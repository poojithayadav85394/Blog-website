**###Blog-website**
Tasks completed during my internship at Code alpha, showcasing my development skills


## Description

Blog Website is a simple web application that allows users to create, view, and manage blog posts. It provides an easy-to-use platform for sharing articles and ideas.

## Features

* Create blog posts
* View blog posts
* Edit and delete posts
* Simple and user-friendly design
* Responsive web pages

## Technologies Used

* HTML
* CSS
* JavaScript


## Project Purpose

This project was developed to practice web development and Flask application development.

## 📚 What I Learned

Through this project, I gained practical experience in:

* Building web pages using **HTML and CSS**
* Adding interactivity using **JavaScript**
* Implementing **CRUD (Create, Read, Update, Delete)** operations
* Organizing a web project using a proper folder structure
* Debugging and fixing application errors
* Understanding the basics of developing and maintaining a complete web application
